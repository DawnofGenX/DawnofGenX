## 🔬 Projects

| | | |
|---|---|---|
| **[Vishwas](https://github.com/DawnofGenX/vishwas)** | ~47.9K LoC · 668 tests | Zero-cloud WhatsApp verification platform. A user messages a number; URLs, executables/APKs, documents (OCR) and images/audio get checked and answered with a plain-language verdict plus a confidence band, in 7 languages. Routing is deterministic — an LLM only narrates finished verdicts, behind a prompt-injection guard. |
| **[UARTScope](https://github.com/DawnofGenX/uartscope)** | ~19.0K LoC · 277 tests | "Wireshark for microcontrollers." Bidirectional UART/I²C/SPI/CAN/Modbus decoders, CAN from vendor DBC files, live charts, threshold alerts, session record/replay with golden-baseline diffing, plugin marketplace, MQTT bridge. |
| **[CiteSure](https://github.com/DawnofGenX/citesure)** | ~15.0K LoC · 422 tests | Local citation verifier (MCP server + CLI). Checks whether a cited source actually *supports* the claim, not just whether the link is alive. Unverifiable claims return "can't verify" instead of a hallucinated verdict. Measured its own INT8 cliff: **86.1% → 66.7%** (93/108 → 72/108; entailment 0.9973 → 0.0274) — the measurement that motivated quant-regress. |
| **[blind-mcp](https://github.com/DawnofGenX/blind-mcp)** | ~1.0K LoC · 14 tests | MCP server for company research on Blind, extended from an upstream MIT scaffold. |
| **[quant-regress](https://github.com/DawnofGenX/quant-regress)** | ~6.5K LoC · 181 tests · CI on py3.10–3.12 | CI gate for quantization damage. On a real Qwen2.5-0.5B-Instruct run, arithmetic accuracy fell **33.3% → 3.3%** (20/60 → 2/60; bootstrap 95% CI 18.3–43.3 pts) and sentiment 98.3% → 3.3%, while perplexity and KL still looked healthy. Every figure in its README is regenerated by a committed script, and a test fails the build if one stops matching. |
